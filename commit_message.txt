refactor: Use .env for configuration loading

This commit updates the application to use .env files for configuration loading instead of config.yaml.

- **Updated `backend/main.go`:** Modified `NewConfig` to use `viper` with `dotenv` type and look for `.env` file.
- **Deleted `config.yaml`:** Removed the old configuration file.
- **Updated `.env`:** Added `INPUT_JSON_PATH`, `DB_PATH`, and `SERVER_PORT` to the `.env` file.
- **Updated `memory-bank/code-smells-refactor.md`:** Reflected the change in configuration loading method.
